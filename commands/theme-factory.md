# Theme Factory

Apply consistent, professional styling to any artifact — slide decks, docs, reports, HTML pages.

## Usage

1. **Show available themes** — list the 10 themes below with their descriptions
2. **Ask for selection** — get explicit confirmation of chosen theme
3. **Apply the theme** — use the selected colors and fonts throughout the artifact

## Application Rules

- Apply colors and fonts **consistently** throughout the entire artifact
- Ensure proper contrast and readability at all text sizes
- Maintain the theme's visual identity — don't mix palettes
- Headers use the display font; body uses the body font

---

## Custom Theme

If none of the 10 themes fit, generate a custom one:
1. Ask for a brief description (mood, industry, audience)
2. Choose appropriate colors and fonts based on the description
3. Give the theme a descriptive name
4. Show the theme spec for review before applying
